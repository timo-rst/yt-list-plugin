# Contributing to Subscriptions List View for YouTube™

Thank you for your interest in contributing to this project!

## How to Contribute

### Reporting Bugs
- Check the [Issues tab](https://github.com/timo-rst/yt-list-plugin/issues) to see if the bug has already been reported.
- If not, open a new issue using the **Bug report** template.
- Please provide details on your browser (Brave, Chrome, Edge), OS, and steps to reproduce.

### Suggesting Enhancements
- Feature requests and improvements are welcome! Please open an issue using the **Feature request** template.

### Pull Requests
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-new-feature`
3. Make your changes:
   - Ensure `node --check content/content.js` passes.
   - Test locally in your browser by loading the extension in `brave://extensions` or `chrome://extensions`.
4. Commit your changes: `git commit -m "Add feature ..."`
5. Push to your branch: `git push origin feature/my-new-feature`
6. Open a Pull Request.
